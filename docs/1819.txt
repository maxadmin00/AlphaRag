Общие правила с 1-го по 2-й месяц; • базовая ставка + надбавка за покупки – для периода с 3-го месяца. Базовая ставка действует на всю сумму минимального остатка. Базовая ставка зависит от тарифа клиента, определяется на начало каждого дня месяца и применяется к фактическому положительному остатку средств на счёте на начало каждого календарного дня месяца. 1. Особенности приветственной надбавки Ставка с приветственной надбавкой действует с 1-го по 2-й месяц включительно для клиентов, у которых не было Альфа-Счёта в рублях, или не было Альфа-Счёта в рублях с положительными минимальными остатками за последние 90 календарных дней. Условия применяются только на один счёт. Приветственная надбавка действует на сумму минимального остатка: • до 30 млн ₽ для клиентов с тарифом «А-Kлуб»; • до 10 млн ₽ для клиентов с тарифом «Alfa Only» / «Максимум +»; • до 1,5 млн ₽ для всех остальных. Свыше максимальной суммы действует только базовая ставка. 2. Особенности надбавки за покупки (POS-оборот) Надбавка за покупки по картам определяется, исходя из тарифа клиента, который действовал у него в последний календарный день месяца (день выплаты процентов по счёту) и применяется к фактическому положительному остатку средств на счёте на начало каждого календарного дня месяца с 1-го дня месяца. Для применения надбавки за покупки учитываются покупки по дебетовым и кредитным картам. Действует на сумму минимального остатка: • до 30 млн ₽ для клиентов с тарифом «А-Kлуб»; • до 10 млн ₽ для клиентов с тарифом «Alfa Only» / «Максимум +»; • до 1,5 млн ₽ для всех остальных. Свыше максимальной суммы действует только базовая ставка. Выплачивается на каждый счёт отдельно: сначала на первый открытый счёт с наибольшим остатком за месяц и далее по убыванию. Если все счета открыты в одну дату, то в приоритете счёт с наибольшим минимальным остатком за текущий месяц. Максимальная сумма для начисления надбавки за покупки применяется исходя из суммы минимальных остатков суммарно по всем открытым Альфа-Счетам на минимальный остаток в рублях. Как определяется минимальный остаток для начисления процентов: • По наименьшей сумме на счёте на начало дня с первого по последний календарный день месяца. • По наименьшей сумме на счёте на начало календарного дня месяца, начиная со следующего дня после первого пополнения счёта по последний календарный день месяца, если: – Альфа-Счёт открыт в том месяце, за который начисляются проценты; – Альфа-Счёт открыт раньше, но минимальный остаток в предыдущем месяце и остаток на первое число этого месяца равны нулю. Как выплачиваются проценты: Все проценты выплачиваем одной суммой, в последний календарный день месяца с 20:00 до 00:00 мск. Проценты по базовой ставке — без ограничения по максимальной сумме, а по приветственной надбавке и надбавке за покупки — с ограничением. Детализацию по начисленным процентам можно посмотреть в истории операций. Процентная ставка начисляется на минимальный остаток по Альфа-Счёту за текущий календарный месяц и округляется по правилам математического округления до двух знаков после запятой. Банк вправе изменять размер процентов (в том числе размер базовой ставки, приветственной надбавки и надбавки за покупки) за пользование денежными средствами, находящимися на банковском счёте клиента в одностороннем порядке (согласно п. 1 ст. 852 Гражданского кодекса Российской Федерации). 4. Особенности надбавки за подписку Альфа-Смарт Надбавка за подписку Альфа-Смарт определяется исходя из наличия / отсутствия подключения клиентом себе или присоединения в качестве участника к подписке Альфа-Смарт другого клиента, в последний календарный день месяца (в период с 20:00 до 00:00 мск): • если в этот период подписка действует (активна), то надбавка применяется и начисляется за весь текущий календарный месяц, начиная с 1-го числа; • если в этот период подписка не действует (неактивна), то надбавка за этот месяц не выплачивается. Максимальная сумма для начисления процентов по надбавке за подписку Альфа-Смарт не установлена. 3. Общие правила Счёт можно открыть в приложении на Android или в Альфа-Онлайн. Проценты по базовой ставке, надбавке за покупки по картам банка и надбавке за подписку Альфа-Смарт начисляем без ограничения по максимальной сумме. В случае досрочного закрытия накопительного счёта, проценты за месяц, в котором был закрыт счёт, выплачены не будут.
