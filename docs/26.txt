Это командное соревнование, в котором участники создают технические решения для продуктов компании за ограниченное время. Обычно хакатоны объединяют программистов, дизайнеров, аналитиков и других специалистов в поисках совместных креативных решений В каком формате пройдёт хакатон? Первый этап — онлайн, а 15 лучших команд отправятся на очный финал в Москву Какие навыки и инструменты мне понадобятся для решения кейса? На старте чемпионата ты получишь специальный учебник по решению кейсов и подборку материалов с актуальными данными по своей задаче. Вот инструменты, с которыми тебе предстоит работать: Версия языка: Python 3.8+ (используем свежие версии) Доступные среды разработки: Jupyter Notebook, Google Colab, VS Code, PyCharm Библиотеки для обработки данных: Pandas, Numpy. Опционально: Scipy, Statsmodels Библиотеки для анализа данных: Matplotlib, Seaborn. Опционально: Plotly, Streamlit, Dash Библиотеки для ML: Sklearn. Любая на выбор: CatBoost, XGBoost, PyTorch, LightGBM Инструменты для выгрузки результатов: Markdown для оформления титульной страницы репозитория, Github — для сохранения и загрузки решений У меня слабый компьютер, я смогу участвовать?
