Текущая версия плагина совместима со следующими версиями Drupal и Drupal Commerce: Drupal — 7.x; Drupal Commerce 1.13; Комбинированный дистрибутив Commerce Kickstart версии 7.x-2.45, который объединяет Drupal версии 7.54 и Drupal Commerce версии 7.x-1.13. Разместить папку с платежным плагином в папку /{путь, где установлена CMS}/modules/; Перейти в «Верхнее меню» → «Модули»; Установить модуль Commerce RBS Payment. Перейти в «Верхнее меню» → «Магазин» → «Конфигурация» → «RBS Payment configuration»; Заполнить поля: Статус — включить или выключить способ оплаты (показывать ли на странице оформления заказа); Логин продавца — логин API пользователя в платежном шлюзе; Пароль продавца — пароль API пользователя в платежном шлюзе; Режим работы — при тестовом режиме модуль взаимодействует с UAT платежном шлюзе, при боевом — с PROD; Стадийность платежа — одностадийные или двухстадийные платежи; Настройки передачи данных в ОФД Система налогообложения — доступны следующие значения: 0 — общая; 1 — упрощённая, доход; 2 — упрощённая, доход минус расход; 3 — единый налог на вменённый доход; 4 — единый сельскохозяйственный налог; 5 — патентная система налогообложения.
