Поменяйте в личном кабинете первоначальные пароли для логинов из письма с продуктивными настройками. Шаг 2. Включите фиксализацию в продуктивной среде, если арендуете онлайн-кассу у наших партнёров. Шаг 3. Настройте оплату одним из способов подключения. Шаг 4. Активируйте приём оплаты. Зайдите в продуктивный личный кабинет. Для этого введите логин с окончанием -api и первичный пароль — они содержатся в письме с инструкцией для подключения к продуктивной среде. Смените пароль для логина -api. Каким должен быть новый пароль: Содержит не менее 12 символов Содержит латинские символы в нижнем и верхнем регистре, цифры, символы из группы: ! " № ; : ? * ( ) + = /\ < > , . {} Вы сменили пароль для логина -api. Теперь выйдите из личного кабинета и заново откройте страницу авторизации. Введите логин с окончанием -operator и первичный пароль из письма на почте. Придумайте новый пароль для логина -operator. Он также должен соответствовать требованиям по количеству и типу символов. Для входа в личный кабинет используйте логин -operator и ваш новый пароль к нему. Логин -api не имеет доступа к личному кабинету. Он нужен при следующих способах подключения: с помощью модуля CMS или интеграции по api. Обратите внимание: вход в личный кабинет с логином -api возможен только один раз для создания нового пароля. Чтобы включить фискализацию в продуктивной среде: Подключите онлайн-кассу, зарегистрированную у одного из наших партнёров. Заполните раздел «Настройки ОФД» в продуктивном личном кабинете. Настройка простых способов подключения без IT-специалиста Выставление ссылки на оплату Чтобы выставить ссылку на оплату реальному покупателю, зайдите в продуктивный личный кабинет и проделайте те же действия, что и во время тестирования. Социальная сеть Чтобы создать ссылку на оплату, перейдите в продуктивный личный кабинет и используйте способ: выставление счёта на оплату в разделе «Счёт на оплату» Конструктор сайтов One Бизнес Зайдите в «Настройки сайта» в разделе «Интеграции» и снимите галочку с тестового режима. Также укажите продуктивный логин -api и новый пароль к нему, который задали ранее. Затем перейдите в конструктор сайтов One Бизнес, нажмите «Создайте сайт бесплатно» и следуйте подсказкам.
