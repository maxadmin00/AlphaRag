11.10.2017 Введены в действие Тарифы по счету «Совместный» для Клиентов Банка в рамках всех ПУ, кроме архивных, и услуга «Альфа-Мобайл» для держателей дополнительных карт. По Пакету Услуг А-клуб меняются тарифы за перевыпуск карты (отменены), добавлены уточнения по лимитам на снятие наличных по кредитным картам для клиентов Аклуба.
