31.01.2019 С 01 февраля 2019 года: — открытие депозита «Потенциал+» будет доступно только клиентам с Пакетами услуг "Максимум+"/"Премиум" и «А-Клуб». — открытие депозита «Премьер+» будет доступно только клиентам с Пакетом услуг «А-Клуб». Для остальных Пакетов услуг / Категорий / Универсальной линейки карт («Альфа-Карта» / «Альфа-Карта с преимуществами») депозиты будут не доступны к открытию. Депозиты, открытые до 31.01.2019г. (включительно) продолжат свое действие до срока их окончания. — открытие накопительного счета «Аэроплан» будет доступно только клиентам с Пакетами услуг "Максимум+"/"Премиум" и «А-Клуб». При этом порядок начисления миль по счету не меняется.
